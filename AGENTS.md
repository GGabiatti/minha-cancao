# Instruções do projeto Minha Canção

## GitHub
O usuário pediu que o projeto seja mantido no GitHub e que toda alteração feita pelo assistente seja sincronizada. Leia GITHUB_SYNC.md. Ao terminar mudanças, valide, faça commit e envie ao repositório vinculado. Não conclua dizendo que está sincronizado sem confirmar o envio. Nunca faça force push nem sobrescreva alterações remotas.

## Produto
Leia PRODUCT.md e DESIGN.md. Preço de R$97 apenas no checkout após o quiz. Não invente estatísticas ou depoimentos. Pagamento e entrega automática não estão conectados; preserve a indicação de prévia até integrar de verdade.

# Sincronização com GitHub

Pedido permanente do usuário: sempre que o assistente alterar este projeto, validar as mudanças, criar um commit descritivo e atualizar o repositório GitHub vinculado antes de concluir a tarefa.

Repositório: aguardando criação na conta GGabiatti. Nome proposto: minha-cancao.

Não substituir alterações remotas sem conferir; nunca usar force push. Não versionar credenciais, arquivos .env, dados de clientes, rascunhos pessoais ou arquivos temporários. Relatar explicitamente qualquer falha de sincronização. Esta instrução não configura monitoramento automático de edições feitas fora das tarefas do assistente.

A hospedagem pública do site é separada do armazenamento do projeto no GitHub. Pagamento e geração de músicas continuam pendentes de integração.
